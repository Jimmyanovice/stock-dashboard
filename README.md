## 📌 项目定位与双线作战目标

本项目为独立封闭的竞赛专项工程，依托郑州商品交易所（CZCE）与中国期货业协会主办的**第九届“郑商所杯”**，实现两项核心任务：
1. **【模拟交易实盘线】**：
   - 客户端：易盛极星 9.5（桌面快捷方式 `郑商杯v9.5` / `%APPDATA%\Epolestar000450v9.5\` 与 `D:\Epolestar000450v9.5\` 双向就绪）；
   - 技术接入：通过极星原生 Python 量化 API（`CZCE_AccountBridge.py`），秒级采集账户权益、持仓与风控快照，保障低回撤与稳定收益；
2. **【学术课题研究线】**：
   - 课题选题：**《基于产业链时空图卷积与自适应趋势门控的商品衍生品动态套保模式研究——以纯碱/玻璃光伏与电子器件产业链为例》**；
   - 申报截止：**2026 年 10 月 8 日**（提交完整《研究计划书》）；
   - 核心创新：将原 `Rainbow-FinGPT` 的非结构化 RAG 认知、产业链时空图卷积（Temporal NALE）与因果趋势门控（Trend Gate）全面引入大宗商品期权与期货动态套保。

## ⚡ 极星 9.5 账户同步启动指南

1. **登录极星 9.5**：
   - 打开极星 9.5，选择站点 **【郑商所杯】** 或 **【金融交易模拟大赛】**；
   - 输入衍生品学苑分配的 **专属模拟资金账号** 及 **交易密码（身份证后6位）**；
2. **加载监控策略**：
   - 在极星 9.5 顶部菜单或侧边栏点击 **【量化】** $\rightarrow$ **【策略管理】**；
   - 在左侧策略树中展开 **【用户策略】**，可以看到自动部署好的 **`CZCE_AccountBridge`**；
   - 双击或右键点击 **“加载运行”**；
3. **查看同步数据**：
   - 运行后，策略会自动将实时资金状态输出至：
     `D:\第九届郑商所杯_2026\02_极星量化与实盘\logs\account_snapshot.json`
   - 后续任何外部策略与风控看板均可实时读取该文件。
